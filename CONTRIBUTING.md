# Contributing

Use Python 3.11+ and R 4.3+ and run the commands in the README before proposing a change. Keep maintained interfaces and documentation in English. Preserve historical source text and its hashes; corrections belong in maintained modules and the review document.

For numerical changes, explain the affected model assumption, units and expected behavior. Test physical accounting or statistical properties rather than only copying formulas from the implementation. Use seeded, small examples and keep generated outputs outside version control except for deliberately selected previews. Do not commit virtual environments, credentials, reports or large notebook output.
